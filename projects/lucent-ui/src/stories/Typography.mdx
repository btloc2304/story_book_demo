# 🔤 Typography

Lucent UI uses **Inter** — a modern, highly-legible sans-serif typeface from Google Fonts — as the primary font across all components.

**Font Family:** `Inter`, sans-serif
<br />
**Weights:** 400 (Regular) · 500 (Medium) · 700 (Bold)
