# 🔤 Kiểu Chữ (Typography)

Lucent UI sử dụng phông chữ **Inter** (một phông chữ sans-serif hiện đại từ Google Fonts) làm phông chữ chủ đạo cho toàn bộ hệ thống.

**Font:** `Inter`, sans-serif
<br />
**Weights:** 400(regular), 500(medium), 700(bold)
